CAD PC 2025 – etapa 1
=====================
Program care arata ca AutoCAD 2025 (interfata in rusa) si lucreaza cu desene DWG si DXF.

Instalare (o singura data)
1. Dezarhiveaza in C:\gisteren\tools\cad_pc
2. Ruleaza CONSTRUIESTE_EXE.bat  ->  dist\CAD_PC\CAD_PC.exe  (si dist\CAD_PC_autonom.exe)
   (sau PORNESTE.bat ca sa pornesti direct, fara exe)

DWG
- Se deschide si se salveaza prin ODA File Converter (gratuit, opendesign.com) daca e instalat,
  altfel prin AutoCAD-ul de pe calculator (AutoCAD 2025 merge). DXF se deschide mereu, fara nimic in plus.
- Originalul nu se atinge la deschidere; la salvare se face o copie .bak.

Ce merge in etapa 1
- Meniul „A” (Создать, Открыть, Сохранить, Сохранить как, Импорт, Экспорт, Закрыть, Последние документы)
- Panglica: toate filele din capturi (Главная, Вставка, Аннотации, Параметризация, Вид, Управление, Вывод, Express Tools…)
- Tab-urile „Начало” + desenul, pagina de start cu fisierele recente
- Desenul: linii, polilinii, cercuri, arce, elipse, spline, hasuri, texte, MTEXT, blocuri cu atribute, cote
- Rotita mouse-ului = zoom; rotita apasata = pan; dublu clic pe rotita = tot desenul
- Straturi: lista din panglica (stratul curent) si „Свойства слоя” (pornit/oprit, inghetat, blocat, culoare, strat nou/sters)
- Linia de comanda: ОТКРЫТЬ, СОХРАНИТЬ, СОХРАНИТЬКАК, ПОКАЗАТЬ (Z), СЛОЙ (LA), РЕГЕН, СЕТКА (F7), ОРТО (F8);
  scrii direct pe desen si merge in linia de comanda; Enter gol repeta ultima comanda
- Bara de jos: Модель / Layout, МОДЕЛЬ, grila, orto si celelalte comutatoare

Etapa 2 – editare si etichete
- Selectie: clic pe obiect; fereastra stanga->dreapta = doar ce e complet inauntru, dreapta->stanga = ce atinge;
  Shift+clic scoate din selectie; Esc goleste; Ctrl+A tot. Obiectele de pe straturi blocate nu se selecteaza.
- ПЕРЕНЕСТИ (M), КОПИРОВАТЬ (CO), ПОВЕРНУТЬ (RO), МАСШТАБ (SC), ЗЕРКАЛО (MI), СТЕРЕТЬ (E / Delete), РАСЧЛЕНИТЬ (X)
  punctele: clic pe desen (cu prindere de capete / centre / puncte de insertie, F3), sau scrii x,y; un numar = distanta pe directia mouse-ului
- ОТМЕНИТЬ / Ctrl+Z, ПОВТОРИТЬ / Ctrl+Y; Ctrl+C, Ctrl+V, Ctrl+X
- ОТРЕЗОК (L), ПЛИНИЯ (PL), КРУГ (C)
- Lista de straturi si de culori din panglica schimba stratul / culoarea obiectelor selectate
- Etichete: ТЕКСТ (DT), МТЕКСТ (T); dublu clic pe text = editare; dublu clic pe bloc = atributele lui
- НАЙТИ / Ctrl+F = „Найти и заменить” (texte, MTEXT si atribute; Показать = zoom la rezultat)
- TCOUNT = numerotare automata (dupa X sau Y, numar de start, pas, inlocuire / prefix / sufix, atributul ales)
- ATTOUT = atributele blocurilor si textele in Excel (cu HANDLE); ATTIN = le citeste inapoi din Excel si le schimba in desen
- Meniurile din bara de stare (☰, ▾ la привязка / полярное / объектная привязка / масштаб, ⚙), bara de acces rapid ▾,
  meniul ☰ al tab-urilor, ☰ Модель/Layout (Новый лист), 🔧 din linia de comanda, „?” si coordonatele

Etapa 3 – simboluri, pagini, tiparire
- ВСТАВИТЬ (I) / „Вставка ▾”: alegi blocul (cu previzualizare), scara si rotatia, apoi clic unde se pune;
  daca blocul are atribute, se cer valorile. „Из библиотеки (DWG/DXF)...”: iei simboluri din alt desen.
- БЛОК (B): din obiectele selectate faci un simbol nou (nume + punct de baza).
- ЗАМЕНИТЬБЛОК: blocurile selectate se inlocuiesc cu alt simbol (atributele se pastreaza dupa nume).
- Pagini: tab-urile de jos Модель / Layout; „+” sau ☰ → „Новый лист” = foaie A3 cu tot modelul; pe foaie: rotita = zoom.
- ПЕЧАТЬ (Ctrl+P): imprimanta sau „Сохранить в PDF”, format A0–A5 (implicit A3), orientare, alb-negru, margini,
  „Просмотр...”; se poate tipari Модель sau oricare foaie.
- ЭКСПОРТPDF / meniul A → Экспорт → PDF.

Titlu si logo (optional, doar la tine)
- titlu.txt langa CAD_PC.exe = textul din bara de sus (ex.: CAD PC – numele firmei)
- logo.png langa CAD_PC.exe = sigla afisata langa titlu si pe pagina de start

Imagini raster (TIFF / GeoTIFF, JPG, PNG) – in coordonate reale
- Вставка → „Присоединить” sau comanda ПРИСОЕД / IMAGEATTACH / TIFF
- pozitia se ia singura din fisierul .tfw (.tifw, .jgw, .pgw, .wld) de langa imagine sau din GeoTIFF;
  daca nu are, scrii coltul stinga-jos X, Y si marimea pixelului
- se salveaza in DWG/DXF ca imagine legata (ca in AutoCAD): tine fisierul TIFF langa desen sau la aceeasi cale
- imaginile mari se micsoreaza in memorie la 4096 px pentru ecran, ca sa nu se umple RAM-ul

Viteza si memorie (desene mari)
- desenul se pregateste in fundal la deschidere; la o modificare se redeseneaza doar obiectele schimbate
- anularea tine doar copiile obiectelor atinse (cu limita de memorie)
- programul lucreaza cu prioritate scazuta si lasa 2 nuclee ale procesorului libere
